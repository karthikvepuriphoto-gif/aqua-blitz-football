# 🐬 Aqua Blitz Football

A kid-friendly football game you play in the browser, on a computer, tablet or phone.

**Play it:** https://karthikvepuriphoto-gif.github.io/aqua-blitz-football/

## Features
- **Choose your position:** Quarterback, Running Back, Wide Receiver, or Defense (linebacker). You can switch at the start of every drive.
- **QB:** throw to receivers A–E (tap their letter or press 1–5), hand off on run plays and control the RB, or scramble.
- **RB:** follow your blockers, juke defenders, sprint for the end zone.
- **WR:** run your route (or let autopilot run it), get open, run under the landing ring, dive for catches.
- **Defense:** chase the ball carrier, dive tackle, switch players, sack the QB, and return interceptions for a pick-six.
- **Strategy:** a playbook of 15 plays, and the defense calls Man, Blitz, Deep Zone or Stack the Box. Read the defense before the snap and audible if needed. The CPU adapts if you keep running the same thing.
- 4th-down decisions, field-goal and extra-point kicking meter, 2-point tries, punts, halftime, overtime.
- **Uniforms:** 8 preset styles (Aqua Home, Orange Crush, Throwback…) plus custom colors, your name and number on the jersey, and your own team name.
- 6 opponents, 3 difficulty levels (Rookie / Pro / All-Pro), 4 quarter lengths.
- Broadcast-style field: blue line of scrimmage, yellow first-down line, crowd, sounds and "Touchdown!" voice.

## Controls
| | Keyboard | Touch |
|---|---|---|
| Move | Arrows / WASD | Joystick (left side) |
| Sprint | Shift | SPRINT |
| Hike / Juke / Dive | Space or Enter | Big orange button |
| Throw (QB) | 1–5 | Letter buttons / tap receiver |
| Call for ball (WR) / Switch (D) / Audible | E | Gray button |

Everything is one file: `index.html`. No build step.
